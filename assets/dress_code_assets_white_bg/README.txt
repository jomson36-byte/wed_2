# Dress Code Assets - White Background

ชุดไฟล์นี้เป็น Assets สำหรับทำ Section **Dress Code** บนเว็บไซต์งานแต่ง  
ออกแบบในสไตล์ **watercolor / garden wedding / elegant cream & sage green theme**

ไฟล์ส่วนใหญ่ถูก Export บนพื้นหลังสีขาว เพื่อให้นำไปจัดวางใน HTML / CSS ได้ง่าย  
เหมาะสำหรับใช้ทำหน้าเว็บแบบ Layer แยกชิ้น, Motion Animation, Scroll Animation หรือ Parallax Effect
