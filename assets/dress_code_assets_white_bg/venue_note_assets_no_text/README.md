# Venue Note Assets (No Text)

This folder contains separated non-text assets extracted from the Venue Note design.
All assets are exported on a white background for HTML / CSS layout use.

## Files Included

- `00_source_venue_note_box.png` — source reference image
- `01_venue_note_outer_frame.png` — outer gold rounded frame with bottom center gap
- `02_high_heel_icon.png` — gold high heel icon
- `03_bottom_flourish_divider.png` — bottom decorative flourish divider with heart motif and horizontal lines

## Suggested Usage

- Use `01_venue_note_outer_frame.png` as the main container outline.
- Use `02_high_heel_icon.png` on the left side of the note.
- Use `03_bottom_flourish_divider.png` at the bottom center of the frame.
- Add the heading and description as HTML text for sharper rendering and better responsiveness.
